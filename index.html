App Updates

Checks the currently deployed GitHub Pages app, clears app caches, and reloads the newest copy without needing a version-file change.

Backup & Restore

Backup Files

Export your complete campaign as a JSON file, including Pokémon, trainers, inventories, money, completed trainers, encounter/reward state, PC level, Kanto route/town visited/completed progress, and gym badge progress. On iPhone or iPad, use Share / Save to Files if you want to place the backup directly in the Files app.

Restore Backup File

Select a JSON backup file from Files. Restoring replaces the campaign currently stored on this device after first creating a safety snapshot.

Manual Backups

Manual snapshots include the same campaign/progress data as exported backups, including Kanto map progress, gym badges, and completed route encounters. The app keeps only the newest 12 manual snapshots.

Automatic Backups

Automatic snapshots include campaign data plus Kanto map progress whenever the app creates a new snapshot. The app keeps only the newest 12 automatic snapshots. Older automatic snapshots are removed automatically.

Reset Campaign

Permanently erase all saved campaign data on this device and return the app to a brand-new campaign: Pokémon, trainers, completed trainers, inventories, money, battle/encounter state, visited/completed map locations, gym badges, local backup snapshots, and campaign level.

Export a backup first if you may want this campaign again.
